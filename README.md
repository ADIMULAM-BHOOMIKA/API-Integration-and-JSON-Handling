# API-Integration-and-JSON-Handling
API Integration & JSON Handling

This project demonstrates how to fetch data from a public API and process JSON data using Python. The program retrieves user information from an API and displays details such as name, email, company, and city.

Technologies Used

- Python
- Google Colab
- Requests Library
- JSON

Features

- Connects to a public API
- Retrieves JSON data
- Extracts useful information
- Displays data in a readable format
- Uses exception handling for errors

Concepts Covered

- API Integration
- JSON Parsing
- Data Extraction
- Error Handling

Output

The program displays user information including:

- Name
- Email
- Company
- City
